# 0012. Поиск по разговорам: индекс в главном процессе, дописывается, резка слов общая

- **Статус:** Принято
- **Дата:** 2026-10-19

## Контекст

Поиск по разговорам ACC (лупа под полем и ⌘F): вкладки «этот чат», «все чаты» и
«спросить Claude», подсветка найденного в ленте и прыжок к сообщению. Транскрипты CLI
большие - сотни мегабайт на проект, и живой разговор дописывает их на каждом шаге.
Нужно искать быстро, не перечитывая всё каждый раз, и красить в ленте ровно те слова,
которые нашёл индекс.

## Варианты

**Индекс в главном процессе, дописывается, копия на диске.**

- Плюсы: окно только рисует; запуск IDE поднимает индекс с копии, а не с транскриптов;
  живой разговор добавляет в индекс только новое.
- Минусы: своя реализация BM25, основы слова и опечаток - кода больше, чем у готовой
  библиотеки.

**Индекс пересобирается целиком на каждое обновление (как в ACC).**

- Плюсы: проще - нет учёта снятых сообщений и отката.
- Минусы: в главном процессе пересборка на каждый шаг живого разговора задерживала бы
  всё окно; в ACC это жило в отдельном потоке JVM.

**Без индекса: поиск по файлам на каждый запрос (`rg`).**

- Плюсы: ничего не хранится.
- Минусы: ни опечаток, ни ранжирования, и сотни мегабайт на каждый запрос.

## Решение

Индекс в главном процессе, который дописывается, с копией в userData и одной резкой слов
на обе стороны (`shared/claude-search-words.ts`): главный процесс называет найденные
термы, лента красит их тем же правилом. Главная причина - скорость на больших
транскриптах без задержек окна.

## Факты и замеры

Индекс на настоящих транскриптах ACC (481 МБ, 80 разговоров), MacBook владельца:
первая сборка - 1,5 с, запуск с копии - 0,2 с, один запрос - 1-23 мс. Повтор - тесты
`main/claude/search/*.test.ts` и открытие окна поиска в копии IDE (скилл `/dev`) на
проекте с длинной историей.

## Последствия

- Резка слов - чистые функции в `shared/`: правило «в shared только типы и данные»
  трактуется как запрет на Node, Electron и React, а не на функции.
- Место находки - id элемента ленты (у человека uuid строки, у ответа `id
сообщения:номер блока`); поменяется нумерация ленты - поменять и в индексе.
- Разговоры прогонов сценариев в индекс не попадают (отсев по книжке скрытых).
- «Спросить Claude» - отдельный `claude -p` в папке корпуса только с Grep, Read и Glob.
- Пересмотреть, если запросы на больших проектах станут дольше 100 мс или память
  индекса заметно вырастет на профиле IDE (ADR 0008).
