# 0013. Удалённый доступ - возможность всей IDE, а не панели Claude Code; пока убран

- **Статус:** Принято
- **Дата:** 2026-10-20

## Контекст

По [ADR 0011](0011-remote-access-acc-protocol.md) удалённый доступ с телефона переехал
из ACC внутрь панели Claude Code: экран Remote access в боковом меню, модуль
`main/remote/`, мост к разговорам панели, «◉ N» в шапке. Так он повторял плагин, но
плагин - это одна панель внутри чужой IDE, а здесь IDE своя. Телефону интересна не
только панель: проекты, файлы, терминал, другие провайдеры LLM. Привязанный к панели,
доступ видел бы только разговоры Claude Code, а его настройки жили бы в меню одного
провайдера.

Владелец решил сделать удалённый доступ на уровне IDE и заняться этим позже.

## Варианты

**Оставить в панели, как в ACC.**

- Плюсы: работает уже сейчас, телефон ACC подключается без правок.
- Минусы: всё, что не панель, телефону недоступно; переезд на уровень IDE потом всё
  равно разберёт мост и экран; до тех пор каждая правка панели тянет за собой мост
  телефона и его белые списки.

**Спрятать строку меню, код оставить.**

- Плюсы: одна правка, вернуть легко.
- Минусы: модуль продолжает подниматься на старте и держать врезки в разговоры,
  сценарии, /btw и поиск; мёртвый код, который надо поддерживать на каждой правке
  панели, и непроверяемый - экрана нет.

**Убрать из панели целиком, код сохранить в архиве.**

- Плюсы: панель и главный процесс не несут того, чем никто не пользуется; врезки для
  телефона (слушатели строк CLI, /btw за чужого, шаги поиска не для окна, флаг
  «с телефона» в очереди) уходят вместе с ним.
- Минусы: при переезде на уровень IDE часть работы придётся поднять из архива заново.

## Решение

Убрать из панели целиком. Решение «где живёт» поменялось, и держать панельную версию
до переезда - значит поддерживать код, который будет переписан. Протокол, криптография,
пара и связь с релеем от места не зависят: их можно поднять из архива, когда доступ
появится на уровне IDE.

## Факты и замеры

Замера нет: решение о месте в продукте, а не о скорости. Панельная версия целиком, со
всеми тестами (крипто на векторах RFC 5869 и WebCrypto, дорога «пара → переподключение →
печать → повтор → отзыв») - в локальной ветке `archive/panel-remote-access`, снимок
рабочего дерева до удаления.

## Последствия

- Нет `main/remote/`, каналов `remote:*`, экранов Remote access и «What travels», «◉ N»
  в шапке панели, пакета `qrcode-generator`.
- Слушатели разговоров (`claude-watchers.ts`) остались только со сменой состояния - их
  слушают сценарии. Строки CLI наружу не уходят, /btw спрашивается только из окна, шаги
  поиска модели - только окну, сценарии не держат слушателей снаружи.
- Файл `remote.json` в userData от прежних запусков больше не читается.
- Удалённый доступ на уровне IDE - новая запись: где живут настройки, что видит
  телефон кроме панели, остаётся ли протокол ACC (ADR 0011).
