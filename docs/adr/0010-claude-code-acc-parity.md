# 0010. Панель Claude Code повторяет раскладку ACC, нарисованную примитивами IDE

- **Статус:** Принято
- **Дата:** 2026-10-19

## Контекст

ADR 0009 выбрал свою реализацию GUI Claude Code на дизайн-системе IDE, с паритетом
«постепенно». Первая версия разложила панель по-своему: селекторы модели, усилия и
режима внутри рамки поля, одна кнопка лимитов вместо колец, настройки - всплывающим
меню на три пункта, решение по плану - карточкой над полем. Экранов Settings не было
вовсе. Владелец продукта каждый день работает в amazing-claude-code (ACC) и сказал
прямо: перенести весь применимый функционал ACC, каждый элемент поставить туда же,
где он стоит в плагине, но нарисовать в дизайн-системе IDE. Исключение - четыре кнопки
шапки IDE (форк, «+», история, меню): их оставить.

## Варианты

**Своя раскладка, функции ACC добираются по одной.**

- Плюсы: панель можно двигать в сторону привычных IDE-чатов, меньше переделки.
- Минусы: человек, привыкший к ACC, ищет каждую кнопку заново; владелец этот путь уже
  отверг. Решения о месте каждого элемента пришлось бы принимать без опоры.

**Раскладка ACC один в один, отрисовка - примитивами и токенами IDE.**

- Плюсы: место каждого элемента уже проверено тысячами часов работы в ACC; перенос -
  это сверка с плагином, а не дизайн с нуля. Дизайн-система IDE не нарушается: меняется
  расположение, а не стиль.
- Минусы: часть решений ACC продиктована JetBrains (Keymap, края окна инструмента) -
  их приходится адаптировать или пропускать осознанно.

## Решение

Раскладка ACC, нарисованная нашими примитивами. Элемент стоит там же, где в плагине:
вкладки в несколько рядов с кнопками справа; под полем строка MODEL / EFFORT /
MODE с кольцами лимитов, токенами за день, облачком отзыва и сердечком; в поле шкала
контекста сверху и ряд «улучшить, вложить, /, поиск, сценарии - Stop, Queue, Send»;
решение по плану - кнопками в карточке плана в ленте; всё прочее - в боковом меню-листе
со своим экраном за каждым пунктом. Главная причина - владелец работает в ACC, и
предсказуемость места важнее собственного вкуса.

## Факты и замеры

Сверка шла с песочницей ACC (`webview`, `pnpm dev`, `harness.html`) и снимками копии
окна IDE (скилл `/dev`). Инвентаризация «что в ACC и где» - по коду и заметкам ACC
(`.claude/rules/*.md` в репозитории плагина). Замеров скорости здесь нет: решение о
раскладке, а не о производительности.

## Последствия

- Настройки панели принадлежат главному процессу (`shared/claude-prefs.ts`,
  `settings/panel-prefs.ts`), окно меняет их патчем `claude:setPrefs` (ADR 0003).
- Боковое меню - примитив `Sheet`; строки меню - `MenuItem` с `iconTone`, `hintTone`,
  `chevron`. Новые примитивы: `Switch`, `Slider`, `RingMeter` (кольцо лимита рисуется
  inline `<svg>` - это данные, а не иконка; исключение помечено в коде).
- Правило «вопросы человеку только над полем» сужено: разрешение и выбор - над полем,
  план - в ленте.
- Не переносится: голосовой ввод (решение владельца, ADR 0009), десять языков
  (интерфейс IDE английский), заставка загрузки (Electron рисует панель сразу),
  раскладки поля «слева» и «справа» (зона 7 всегда справа), анонимная статистика
  использования (внешний сервис ACC без продукта IDE).
- Ветка и PR, которые в ACC стоят справа от вкладок, живут в шапке окна (2026-10-20,
  решение владельца): ветка там уже была, второй раз в панели она не нужна. PR - кнопка
  справа от ветки со значком состояния, открывает PR в браузере; PR нет - кнопки нет.
- Статистики и ачивок в панели нет (2026-10-20, решение владельца): строка Statistics в
  меню, вкладка и книга статистики убраны. Статистика будет своей у IDE, по всем
  провайдерам, а не частью GUI одного из них. Счётчик токенов за сегодня у поля остался
  со своим подсчётом по сегодняшним транскриптам CLI (`usage/today-tokens.ts`).
- Отзыва автору и праздничного слоя в панели нет (2026-10-20, решение владельца): убраны
  строка Send feedback в меню, облачко отзыва под полем, экран отчёта с журналом
  диагностики, гирлянда и снег. Сердечко и карточка автора остались, их ссылки
  открываются каналом `claudePanel:openAuthorLink`.
- Сердечка, карточки автора и «улучшить промпт» в панели тоже нет (2026-10-20, решение
  владельца): убраны сердечко в строке под полем с меню благодарности, рекламная карточка
  внизу бокового меню (вместе с каналом `claudePanel:openAuthorLink` и показанием Heart в
  Settings → Indicators), звёздочка в ряду кнопок поля, экран Settings → Improve prompt и
  разовый запуск CLI, который переписывал черновик. Сценарии ушли на уровень IDE
  ([ADR 0014](0014-scenarios-ide-level.md)), ряд кнопок поля теперь - «вложить, /, поиск -
  Stop, Queue, Send».
- Кнопок шапки IDE теперь три, а не четыре (2026-10-20, решение владельца): «+», форк,
  меню - в таком порядке. Кнопки истории нет, прошлые разговоры открываются строкой
  бокового меню и командой /resume.
- Пересмотреть, если владелец уйдёт из ACC в IDE насовсем и раскладка перестанет быть
  ориентиром - тогда её можно менять по своим причинам.
