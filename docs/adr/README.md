# Журнал решений (ADR)

Решения, к которым не хочется возвращаться дважды. Каждая запись отвечает на три
вопроса: что решили, из чего выбирали и на каких фактах. Где есть замер - он важнее
формулировок: пересмотр начинается с повторного замера, а не с мнений.

Запись не переписывают, когда решение меняется: заводят новую, а старой ставят статус
«Заменено [новой](...)». История решений и есть ценность этой папки.

Новая запись - скиллом `/adr` или по шаблону [0000-template.md](0000-template.md):
следующий номер, имя файла `NNNN-короткое-имя.md`, строка в таблице ниже.
