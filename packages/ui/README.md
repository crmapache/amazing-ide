# @amazing-ide/ui

Дизайн-система Amazing IDE: плоское тёмное стекло ([ADR 0006](../../docs/adr/0006-design-system-flat-glass.md)).
Чёрная рама окна, графитовые полупрозрачные панели со скруглением и тонкой рамкой,
оранжевый - акцент и сигнал внимания, зелёный - «в порядке», мятный - справка.
Объёма нет: ни бликов, ни теней у кнопок и полей.

Вся система на одном экране - витрина: `pnpm dev`, поиск действий (⌘⇧A) → «Show or Hide
Design System».

## Как подключать

По одному примитиву, без общего индекса:

```ts
import type { AvatarTone } from '@amazing-ide/ui/Avatar.types'
import { Button } from '@amazing-ide/ui/Button'
import { usePopover } from '@amazing-ide/ui/Popover.hooks'
```

Стили - `@use '@amazing-ide/ui/mixins' as *;` в `.module.scss`.

## Язык стиля

- **Поверхности.** Рама окна (шапка, вкладки, строка состояния) -
  `--color-surface-chrome`, панели - `--color-surface-panel`, редактор - плотный
  `--color-surface-editor`, плитки внутри панели - `--color-surface-raised`, поля -
  `--color-surface-sunken`.
- **Состояния - слоями.** Наведение `--color-bg-hover`, нажатие `--color-bg-active`,
  выбранное - заливка `--color-bg-selected`. Свечения и цветных черт у выбранного нет.
- **Цвет значит смысл.** Оранжевый - главное действие и «обрати внимание», зелёный -
  «в порядке», красный - ошибка, мятный - справка, жёлтый - предупреждение.
- **Тонированная плашка** (`tinted-plaque`) - цветной текст и тонкая рамка на подложке
  того же тона. Ей нарисованы главная кнопка, значок проекта, мягкая метка.
- **Подписи разделов и статусов** - капсом с разрядкой (`caps-label`).
- **Объём запрещён.** Ни бликов, ни градиентов, ни теней у кнопок, полей, панелей.
  Тень (`--shadow-overlay`) есть только у всплывающих слоёв (`glass-overlay`), плюс
  кольцо фокуса. Держит stylelint: градиенты и `drop-shadow` вне токенов, тень у
  текста и любая другая тень не пройдут.
- **Подсветка кода** - роли `--color-syntax-*` на той же палитре: ключевые слова
  фиолетовые, строки зелёные, функции стальные, числа и константы персиковые,
  комментарии серые курсивом. Контраст каждого тона на `--color-surface-sunken` - не
  ниже 4.5:1.
- **Радиусы мягкие:** метки `xs`, контролы `sm`, строки меню `md`, плитки `lg`,
  панели и всплывающие слои `xl`.

## Правила

- **Расширять - по ступеням:** готовый примитив → вариант существующего →
  композиция в фиче → новый примитив; для токенов: роль → смешение тона → новая
  роль → новый цвет палитры. Подробно - `.claude/rules/design-system.md`. Новый
  примитив сразу попадает в витрину и в таблицу выше, новый токен - в витрину: иначе
  падает тест `showcase.coverage.test.ts`.
- **Значения - только токенами.** Цвет, шрифт, кегль, отступ, радиус, слой, тень,
  длительность и кривая анимации в стилях пишутся через `var(--...)`. Это держит
  stylelint, и он же не пропустит ссылку на токен, которого нет. Нужного токена нет -
  он добавляется в `tokens.css`.
- **Компонент берёт роль, а не палитру:** `--color-surface-panel`, а не
  `--palette-graphite-800`.
- **Вариант, а не копия.** Нужна кнопка чуть иначе - новый `variant` или `size`
  существующей, а не `DangerButton` рядом. Отдельный компонент - только когда другая
  семантика (как `Button` и `IconButton`).
- **Примитив не знает про IDE.** Ни проектов, ни файлов, ни IPC. Импортировать
  приложение пакет не может - это проверяет линтер.
- **Текста внутри нет.** Все строки приходят пропсами, переводы - забота приложения.
- **Иконки - lucide-react**, inline `<svg>` запрещён.
- **Подсказка - `Tooltip`, не `title`.** Системный `title` выглядит чужим, ESLint
  его на элементах не пропустит.
- Hover и active - на одном свойстве, hover в `@media (hover: hover)`, без
  `transform: scale`. Готовое поведение - миксин `interactive-surface`.
