# @amazing-ide/ui

Дизайн-система Amazing IDE. **Пока заглушка**: одна тёмная тема, минимальный набор
токенов и примитивы - ровно то, что нужно каркасу окна. Разрабатывается
отдельно; правила ниже действуют уже сейчас.

## Что внутри

| Путь                            | Что                                                                                                                                                 |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/styles/tokens.css`         | Токены: палитра (`--palette-*`) и роли (`--color-*`), шрифты, отступы, радиусы, размеры зон, слои, движение. Единственное место с сырыми значениями |
| `src/styles/base.css`           | Сброс и база окна. Подключается один раз, после токенов                                                                                             |
| `src/styles/_mixins.scss`       | Поведение без значений: сброс кнопки, обрезка текста, hover/active, области перетаскивания окна                                                     |
| `src/components/Button`         | Кнопка с текстом: primary, secondary, ghost                                                                                                         |
| `src/components/IconButton`     | Кнопка только с иконкой, подпись обязательна                                                                                                        |
| `src/components/DropdownButton` | Тихая кнопка с текущим значением и стрелкой: открывает список (проект, ветка)                                                                       |
| `src/components/Avatar`         | Цветной квадрат с инициалами: значок проекта                                                                                                        |
| `src/components/Toast`          | Карточка уведомления. Сама себя не позиционирует                                                                                                    |
| `src/components/ResizeHandle`   | Ручка изменения ширины панели, мышь и стрелки                                                                                                       |
| `src/components/EmptyState`     | Пустая зона с объяснением и действием                                                                                                               |
| `src/components/Popover`        | Всплывающая панель под кнопкой. Popover API + CSS anchor positioning; связку с кнопкой даёт `usePopover`                                            |
| `src/components/Menu`           | Меню в панели: стрелки, Home/End, фокус при появлении (`autoFocus`, `data-autofocus`)                                                               |
| `src/components/MenuItem`       | Пункт меню: иконка или значок, подпись, вторая строка, подсказка справа, «текущий»                                                                  |
| `src/components/MenuSection`    | Группа пунктов с заголовком, может сворачиваться; во время поиска раскрыта                                                                          |
| `src/components/MenuSeparator`  | Линия между группами                                                                                                                                |
| `src/components/TextField`      | Поле ввода с подписью, иконкой и ошибкой под полем                                                                                                  |
| `src/components/Dialog`         | Модальный вопрос на нативном `<dialog>`: Esc закрывает, Enter подтверждает                                                                          |

## Как подключать

По одному примитиву, без общего индекса:

```ts
import type { AvatarTone } from '@amazing-ide/ui/Avatar.types'
import { Button } from '@amazing-ide/ui/Button'
import { usePopover } from '@amazing-ide/ui/Popover.hooks'
```

Стили - `@use '@amazing-ide/ui/mixins' as *;` в `.module.scss`.

## Правила

- **Значения - только токенами.** Цвет, шрифт, кегль, отступ, радиус, слой, тень,
  длительность и кривая анимации в стилях пишутся через `var(--...)`. Это держит
  stylelint. Нужного токена нет - он добавляется в `tokens.css`.
- **Компонент берёт роль, а не палитру:** `--color-bg-panel`, а не `--palette-gray-850`.
- **Вариант, а не копия.** Нужна кнопка чуть иначе - новый `variant` или `size`
  существующей, а не `DangerButton` рядом. Отдельный компонент - только когда другая
  семантика (как `Button` и `IconButton`).
- **Примитив не знает про IDE.** Ни проектов, ни файлов, ни IPC. Импортировать
  приложение пакет не может - это проверяет линтер.
- **Текста внутри нет.** Все строки приходят пропсами, переводы - забота приложения.
- **Иконки - lucide-react**, inline `<svg>` запрещён.
- Hover и active - на одном свойстве, hover в `@media (hover: hover)`, без
  `transform: scale`. Готовое поведение - миксин `interactive-surface`.
