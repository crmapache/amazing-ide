# Главный процесс и preload

- **Слои:** обработчик IPC (`main/ipc/register-handlers.ts`) только разбирает и
  проверяет запрос и зовёт сервис. Логика - в сервисах (`main/<область>/*-service.ts`).
  Чистые переходы и разбор - в функциях без Electron рядом, с тестом `*.test.ts`
  (как `workspace-state.ts`).
- **Состояние предметной области живёт здесь.** Сервис держит его в памяти, пишет на
  диск (`storage/json-file.ts`, атомарно) и после каждого изменения шлёт событие
  окну через `broadcast`. Окно не владеет этими данными.
- **Окну не верим:** строки из запроса проверяются (`assertString`), пути - через
  `resolveInsideRoot`, отправитель - `isTrustedSender` (уже в `registerInvokeHandlers`).
- **Безопасность окна не ослаблять:** `sandbox: true`, `contextIsolation: true`,
  `nodeIntegration: false`, навигация запрещена, внешние ссылки - в браузер. Нужно
  что-то из Node в окне - это новый канал IPC, а не ослабление.
- **Preload** - только мост из контракта. Логики в нём нет.
- **Файлы внутри бандла приложения** (.app, app.asar) удаляются и копируются через
  `node:original-fs`: обычный `fs` в Electron считает `app.asar` папкой и падает.
- **userData** в dev - отдельная папка «Amazing IDE Dev», с `AMAZING_IDE_PROFILE_DIR` -
  папка профиля (`main/app-profile.ts`). Не смешивать с установленной IDE.
- Ошибка, которую должен понять человек, уходит в окно кодом причины (как
  `UpdateFailureReason`), а текст - через i18n окна. Подробности - в журнал
  (`console.warn`). Русский текст исключения в английский интерфейс не попадает.
- **Нативный вызов macOS**, которого нет в Electron, - через koffi, как
  `usage/phys-footprint.ts` (ADR 0008), а не новым аддоном. koffi грузить на первом
  вызове, а не импортом на старте: сам он грузится около 25 мс.
- Лимит - 300 строк на `.ts`. Сервис разросся - делить по ответственности.
