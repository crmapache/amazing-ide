# Стенд: движок редактора

Сравнение CodeMirror 6 и Monaco для зоны 6 (редактор). Результаты и решение -
[ADR 0005](../../docs/adr/0005-editor-engine.md). Вариант `monaco-shiki` - Monaco с
подсветкой IDE (грамматики shiki, код из `apps/desktop`): цена TextMate против Monarch,
[ADR 0018](../../docs/adr/0018-editor-tabs-autosave-highlighting.md).

Стенд не входит в workspace: у него свои зависимости (Monaco весит десятки
мегабайт), и основной `pnpm install` их не тянет.

## Запуск

```
cd bench/editor
pnpm install --ignore-workspace
pnpm bench
```

Около десяти минут. Только два варианта Monaco: `BENCH_ENTRIES=monaco,monaco-shiki
BENCH_ENGINES=monaco,monaco-shiki pnpm bench`. Вариант `monaco-shiki` берёт shiki из
`apps/desktop`, поэтому сначала нужен основной `pnpm install` в корне. Окна стенда появляются по очереди, но фокус не забирают. Итог -
таблица в консоли и `results.json`.

`node parse-cost.mjs` - цена разбора TypeScript парсером CodeMirror без окна:
полный разбор, узлы-ошибки, повторный разбор после вставки символа.

## Что меряется

Оба движка - в том же Electron, что и IDE, каждое измерение в новом окне:

- **размер сборки** - весь JS, CSS, шрифты и воркеры движка, сжатый и нет;
- **старт** - от начала загрузки страницы до первого кадра с редактором;
- **память** - куча JS после сборки мусора и рабочий набор процесса окна;
- **ввод** - 60 нажатий подряд через `sendInputEvent` (настоящий путь ввода
  Chromium), задержка от события `keydown` до кадра, в котором редактор уже
  обработал ввод. Медиана, p95 и максимум; в середине файла и на 90% его длины;
- **переход в конец** - курсор в конец файла и прокрутка, до кадра.

Файлы: сгенерированный TypeScript на 2 000 и 200 000 строк и два настоящих больших
файла из `amazing-claude-code/webview/src` (`protocol.ts`, `App.tsx`), если проект
лежит рядом.

Настройка движков одинаковая по смыслу: правка как в обычном редакторе (поиск,
сворачивание, мультикурсор, история, скобки), подсветка TypeScript. Автодополнение
и миникарта выключены у обоих: подсказки в IDE даст языковой сервер, сравнивается
ядро. Monaco - без встроенного языкового сервиса TypeScript по той же причине.
